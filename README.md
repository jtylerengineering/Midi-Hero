# Midi-Hero
## Description
The MIDI-Hero is a custom MIDI that mimics a *Guitar Hero* controller that was created as a Week 3 submission for Hack Club's ten week long Half Life event. The board is powered by a Waveshare ESP32 S3 microcontroller with firmware that utilizes the "ESP32 BLE Gamepad" library created by [lemmingDev](https://github.com/lemmingDev).

### 3D printing
If you want the case and keycaps, you will need to either print them yourself or get them printed. I used PLA for my filament. Something to keep in mind, however, is that you will need a 0.2 mm nozzle for your printer. the tolerance needs to be rather tight, and you won't get that very well with a 0.4 mm nozzle.
All of the STL files are in the STL folder.
